Breeze for Bootstrap 6

The Breeze design system as a theme for Bootstrap 6. Classes and JavaScript come from Bootstrap, the look comes from Breeze.

v1.0.0-alpha.4 Bootstrap 6.0.0-alpha.1

Usage

Prebuilt CSS, or the Sass source for projects with their own build.

Prebuilt CSS (e.g. Java, PHP, CMS)

Copy dist/breeze.min.css into the project. It contains all of Bootstrap 6 – don’t load Bootstrap itself. Take the JavaScript (dialogs, menus) from the Bootstrap package.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Figtree:wght@400;500;600;700&family=Titillium+Web:wght@400;600;700&display=swap">
<link rel="stylesheet" href="/css/breeze.min.css">

Sass in a project with a build

Breeze loads Bootstrap itself. Afterwards, prefix the CSS variables with PostCSS (postcss-prefix-custom-properties, prefix bs-) – see the README.

@use "breeze/scss/breeze" with ($auto-dark-mode: false);

Dark theme and your own styles

Turn on the dark theme with data-bs-theme="dark" on <html> (data-theme="dark" and the dark class work too). Your own CSS outside layers overrides Breeze without !important. Tokens: var(--bs-color-primary).

Colors

The Breeze semantic colors as --bs-color-*. Bootstrap themes are derived from them (theme-primary, bg-canvas …).

Typography

Titillium Web for headings and amounts, Figtree for text and forms. Bootstrap 6 sizes – from lg up they grow with the viewport.
