# Progress

Tenký ukazovateľ postupu s popiskom — „Krok X z Y“, vyplnenie formulára, sila hesla.

**Konzument dodá:** `value`, `max`, voliteľne `label` (`''` skryje), `tone` (`primary` | `success` | `warning` | `danger`).

- Dráha `h-1 rounded-full bg-line`, výplň podľa `tone`; popisok `text-sm text-ink-muted`. Tón vždy doplňte slovom v popisku.
