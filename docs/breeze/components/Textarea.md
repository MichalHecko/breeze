# Textarea

Viacriadkové pole s rovnakým vzhľadom ako `TextField` a voliteľným počítadlom znakov.

**Konzument dodá:** `label`, voliteľne `hint`, `error`, `optional`, `maxLength` (zobrazí „n / max“), `rows`, `value`/`onChange` alebo `defaultValue`.

- `min-h-28`, `py-3`, `rounded-lg` (ako tlačidlo), `resize-y`; ostatné ako `TextField`.
- Počítadlo je vpravo pod poľom v `text-ink-muted tabular-nums`.
