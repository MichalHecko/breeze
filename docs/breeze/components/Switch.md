# Switch

Prepínač zap/vyp s popiskom vľavo — pre nastavenia, ktoré platia hneď.

**Konzument dodá:** `label` alebo `aria-label`, voliteľne `description`, `checked`/`onChange(boolean)` alebo `defaultChecked`, `disabled`.

- Dráha `h-6 w-11 rounded-full`, vypnutý `bg-line-strong`, zapnutý `bg-primary`; jazdec `size-5 bg-surface shadow-sm`.
- `role="switch"` s `aria-checked`; fokus jemná žiara `ring-4 ring-primary/25` (ako v Bootstrape).
